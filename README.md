Entry for the make.fun competition [Invent a Word We Need](https://make.fun/competitions/u-deranalabs-invent-a-word-we-need-17a020e0).

The program coins one new English word and defines it in a single line: **pingraze** — to repeatedly skim notifications without opening or acting on them.

## Run

```sh
python3 main.py
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset).
